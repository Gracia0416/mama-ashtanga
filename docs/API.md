# Booking API

Development endpoint:

```text
https://nvkbobgmrxkjttjvxddl.supabase.co/functions/v1/booking-api
```

The API is deployed as the Supabase Edge Function in `supabase/functions/booking-api`.

## List available sessions

```http
GET /sessions?from=2026-09-13T00:00:00Z&to=2026-12-13T00:00:00Z
```

The response contains public class information and remaining places. `booking_open` is false inside the 24-hour advance-booking window.

## Create a booking

```http
POST /bookings
Content-Type: application/json

{
  "sessionId": "session UUID",
  "name": "Customer name",
  "email": "customer@example.com",
  "phone": "+60123456789",
  "partySize": 1,
  "paymentMethod": "cash",
  "preferredTime": null,
  "note": "Optional note",
  "requestId": "a new UUID generated by the browser"
}
```

For Monday private appointments, `preferredTime` is required in `HH:MM` format. It must be omitted for the fixed Friday group class.

The API returns the booking reference, safe booking details, a private management token, and a prepared WhatsApp URL for Wirni. The website must preserve the management token in the management link. It must never place the token in analytics or logs.

The database locks the session and checks capacity before inserting the booking. `requestId` protects against accidental double submission.

## View one booking

```http
GET /booking?token=PRIVATE_MANAGEMENT_TOKEN
```

This returns only the booking associated with that token. It includes booking and payment status plus `can_cancel`.

## Cancel a booking

```http
POST /cancel
Content-Type: application/json

{
  "token": "PRIVATE_MANAGEMENT_TOKEN",
  "reason": "Optional reason"
}
```

The database accepts the cancellation only for a confirmed booking at least 24 hours before class. A successful cancellation changes the record's status and restores its places; it does not delete history.

## Current limitations before public launch

- Email verification and confirmation delivery are not connected yet.
- The customer must save the management link until email delivery exists.
- CAPTCHA and endpoint rate limiting are not connected yet.
- The CORS policy currently permits development requests from any origin.
- Private pricing is not decided, so private bookings create no payment row.
- The website still uses its earlier static calendar and WhatsApp-only submission flow.
